# Studentreisen

Midgard-banner, innlogging, faktiske intervjumailer, avlysning og opptaks-/avslagsmail mangler. Bildene nedenfor dokumenterer eksisterende skjema og separat IAM-mal, ikke en sammenkoblet produksjonsflyt.

Alle kandidatdata er syntetiske. IAM-mailen viser malens eksempelpassord, ingen ekte innloggingsopplysninger.
