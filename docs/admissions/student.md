# Studentreisen

Hugin and Midgard now use the real authenticated admissions flow backed by Convex. The `live-` screenshots below are captured from the local isolated backend with synthetic accounts; they show UI and local state, not live external mail, calendar, Slack, or IAM delivery.

The other numbered screenshots are older local UI previews and sample IAM email assets. They are not evidence of a production provider transaction. No real applicant data is used.
